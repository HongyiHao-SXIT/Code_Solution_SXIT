# Code_Solution_SXIT

这是我的计算机系学习阶段开源代码仓库，汇总了：

- 课程实验作业代码
- 课程设计项目代码
- 毕业设计（含相关系统/模块）代码

本仓库用于学习记录、能力沉淀与经验分享，也欢迎同学们参考交流。

## 项目定位

本项目是一个综合性学习代码集合，覆盖 C/C++、Java、Python、前端、数据库、操作系统、数据结构等方向。代码以教学实践为主，强调：

- 基础能力训练（语法、算法、数据结构）
- 工程能力训练（项目结构、模块划分、构建运行）
- 综合能力训练（课程设计与毕业设计实践）

## 目录概览

> 以下为主要目录说明（按当前仓库组织）：

- `C_Lab/`：C 语言实验代码
- `CPP_Lab/`：C++ 实验、练习与教材配套代码
- `Data_struct/`：数据结构实验（排序、AVL 树、哈夫曼编码等）
- `Operating_System/`：操作系统实验（银行家算法、进程/存储管理等）
- `Java_Lab/`：Java 基础与章节实验代码
- `JavaEE_Lab/`：Java Web/EE 相关实验代码
- `Py_Lab/`：Python 基础实验代码
- `SQL_Lab/`：SQL 语句与数据库实验脚本
- `Student_info_manage/`：学生信息管理相关项目（CMake 工程）
- `frontend/`：前端项目（Vite）
- `Academic_Map/`：Java/Maven 项目（含课程项目结构）
- `abroadInfo/`：Python 爬虫与信息处理相关代码
- `Gomoku/`：五子棋项目
- `EcoGuard/` 毕业设计相关综合项目（含后端、推理、模拟等模块）

## 技术栈

仓库中涉及但不限于以下技术：

- 语言：C、C++、Java、Python、JavaScript、SQL
- 前端：HTML、CSS、Vite、Node.js 生态
- 后端与脚本：Flask/Python 脚本、Java 项目结构

## 如何使用

由于本仓库包含多个独立子项目，请按目录分别运行。

### 1. 克隆仓库

```bash
git clone https://github.com/HongyiHao-SXIT/Code_Solution_SXIT.git
cd Code_Solution_SXIT
```

### 2. 进入对应目录后按项目说明执行

常见方式：

- C/C++：使用 GCC/G++ 或 IDE（如 CLion、Visual Studio）编译运行
- Java：使用 JDK + Maven 或 IDE（如 IntelliJ IDEA）
- Python：建议创建虚拟环境后安装 `requirements.txt`
- 前端：执行 `npm install` 后 `npm run dev`
